
# Interactive Business Dashboard & KPI Visualizations

## Project Overview
This project demonstrates an interactive business intelligence dashboard
built using Python, Streamlit, Pandas, and Plotly.

It helps users explore business performance through executive KPIs,
monthly revenue trends, category analysis, and geographic visualizations.

## Objectives
- Monitor total revenue and average order value.
- Calculate customer acquisition cost.
- Analyze customer churn.
- Explore regional and monthly revenue patterns.
- Support interactive business analysis using filters.

## Key Performance Indicators
- Revenue = Sum of revenue
- CAC = Acquisition spend / New customers acquired
- Churn Rate = Customers lost / Customers at start * 100
- AOV = Revenue / Number of orders

## Dashboard Features
- Interactive month, region, and category filters
- Executive KPI cards
- Monthly revenue area chart
- Category performance chart
- Geographic revenue map
- Regional revenue heatmap
- Filtered data export to CSV
- Dashboard report export to PDF

## Tools Used
- Python
- Pandas
- Streamlit
- Plotly
- FPDF2
- GitHub

## Dataset
The included dataset contains illustrative sample business data.
It is not verified company data and should not be interpreted as
actual organizational performance.
